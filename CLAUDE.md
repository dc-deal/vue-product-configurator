## Projektkontext

Ein interaktiver Produkt-Konfigurator als Vue 3 Web Component, einbettbar in eine
bestehende Website (z. B. WordPress) eines mittelständischen Maschinenbauers.
Kein Backend, keine API — alles läuft auf Fixtures.
